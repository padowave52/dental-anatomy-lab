# Dental Anatomy Lab V35 — FDI 32개 고정 매칭

- 사용자가 확인한 32개 FDI↔객체 매칭을 실제 `teeth_model_transparent.glb` 노드명에 맞게 반영했습니다.
- 원본 사용자 목록에서는 점(`.`)과 콜론(`:`)이 생략되어 있었으므로 원본 GLB에 기록된 정확한 이름을 사용했습니다.
- **치아 번호·설명 직접 편집, 관리자 PIN, 브라우저 저장값, 공용 설정 JSON 로드는 모두 제거했습니다.**
- 기존 32개 컬러 `tooth_XX_annotated.glb` 파일과 360도 회전/투명도/표면 학습 유지.
- 원본 객체명 확인 및 CSV 다운로드는 검수용으로 남겼습니다.

## 배포
압축을 푼 폴더 **안의 파일 전체**를 GitHub 저장소 최상위에 업로드하여 교체하세요.
구버전의 `teeth_config.json`은 더 이상 사용하지 않습니다.
GitHub Pages 반영 후 Ctrl+Shift+R을 눌러 캐시를 새로고침하세요.

## 주의
원본 객체명-번호 대응은 사용자가 직접 검수한 표를 기준으로 합니다. 실제 브라우저에서 모든 클릭과 컬러 표시를 완주 테스트한 결과는 아닙니다.


## V36 변경사항
- Three.js GLTFLoader의 노드 이름 정규화(`.` 및 `:` -> `_`)로 인해 선택되지 않았던 상악 좌측 22~26,28 / 하악 좌측 31~38 모델(총 14개)의 객체명 매칭을 복구했습니다.
- 객체 이름과 FDI 32개 고정 연결을 유지합니다. 직접 번호 편집은 필요하지 않습니다.
- 실제 GitHub Pages에서 클릭 및 파일 로딩 여부는 배포 후 테스트가 필요합니다.
