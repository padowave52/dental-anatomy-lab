# Dental Anatomy Lab V37

## 사용
- 메인: `index.html`.
- 우측 상단 **관리자** → `admin.html` → 간편 잠금 암호를 입력해 편집합니다.
- 관리자 화면은 치아 3D 메시 클릭뿐 아니라 **원본 객체명 목록**에서도 32개 메시를 고를 수 있습니다.
- FDI 지정 후 **선택한 치아 번호 저장**을 누르면 같은 브라우저 메인 화면에서 즉시 반영됩니다.
- **공용 설정 JSON 다운로드** 버튼으로 `teeth_config.json`을 저장한 뒤 GitHub 저장소 최상위에서 기존 파일과 교체하면 모든 방문자에게 반영됩니다.
- `tooth_XX_annotated.glb`를 선택한 FDI에 연결하므로 **선택 치아만 보기**에서 해당 컬러 GLB가 열립니다.

## 주의
- GitHub Pages는 정적 호스팅입니다. 브라우저에서 저장한다고 GitHub에 자동으로 업로드되지 않으며 **다른 컴퓨터에 자동 공유되지 않습니다**.
- 클라이언트 코드에 포함된 간편 비밀번호는 브라우저 개발자 도구로 발견/우회할 수 있습니다. **실제 관리자 보안이 아닙니다.** 공개 웹사이트에서는 이를 인증 보안으로 사용하지 마세요.
- 운영 환경에서 안전한 중앙 저장을 원하면 Supabase Auth 등 실제 서버 측 권한 검증이 필요합니다.
- 3D 모델별 정확한 해부학 매칭은 관리자에서 눈으로 확인해 수정해야 합니다.
