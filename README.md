# Dental Anatomy Lab V32 — PIN 1234 간편 편집

## 사용 방법
1. 이 폴더 안의 파일 전체를 GitHub Pages 저장소의 최상위에 업로드합니다.
2. 홈페이지에서 번호가 없는 치아도 직접 클릭해 선택합니다.
3. `치아 번호·설명 직접 편집하기`를 열고 비밀번호 `1234`만 입력합니다. 이메일/아이디는 없습니다.
4. FDI 번호/설명을 수정한 후 `이 치아 저장`을 누릅니다. 변경 내용은 **해당 브라우저에 저장**됩니다.
5. **모든 방문자에게 적용**: `공용 설정 다운로드`에서 `teeth_config.json`을 받은 뒤 GitHub 저장소 최상위의 동명 파일을 교체하고 Commit합니다. 새로 접속하거나 새로고침한 사용자는 공용 번호/설명을 봅니다.

## 알아둘 점
- PIN `1234`는 화면 편집을 잠그는 편의 기능으로, 공개 정적 HTML에서 읽을 수 있으며 안전한 관리자 인증이 아닙니다.
- GitHub Pages는 정적 호스팅입니다. 홈페이지에서 `이 치아 저장`만 눌러서는 다른 컴퓨터나 GitHub에 **자동 동기화되지 않습니다**.
- 진짜 로그인과 즉시 공용 저장이 필요하면 Supabase/Firebase 등 서버 및 인증 설정이 필요합니다.
- 번호 없는 치아의 클릭 판정은 V31에서 수정한 방식을 유지했지만, 실제 브라우저에서 모든 14개 치아를 끝까지 테스트하지는 못했습니다.
